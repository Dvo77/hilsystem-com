THE HOME BRAIN

Current smart homes know state — the light is on, the door is open. They don't know context — what's next to it, who owns it, when it was last serviced, what circuit it's on, or what it cost. HIL provides the context. HA provides the nervous system. The result is a home that can actually reason about itself — and eventually run on a box you own outright.
