## The Index

**Type:** Newsletter / Publication
**URL:** newsletter.hilsystem.com
**Sending address:** news@hilsystem.com
**Platform:** Beehiiv (free tier, up to 2,500 subscribers)
**Status:** Live — Issue 01 pending publication

**Purpose:** The Index is the official newsletter of HIL System. It teaches organization systems, inventory logic, and household management through history, psychology, case studies, and practical tips. It is valuable to the reader whether or not they ever use or purchase HIL System tools.

---

## Mission

> "Everything has a place. Everything can be found. Everything can be learned."

The Index is closer to a field journal or workshop manual than a startup newsletter. Think Popular Mechanics, Field Notes, county plat books. Not SaaS. Not productivity hacks. Every issue teaches a system.

---

## Segments

**Anchor Content — runs every issue or near-every issue:**
- 🧠 Psychology of Collecting — hoarding vs. collecting vs. curating. Mental cost of disorder. Most shareable content.
- 📜 The Indexers — historical figures who built systems. Melvil Dewey, Ellen Swallow Richards, Frederick Winslow Taylor, Herman Hollerith, Marie Neurath. One person per issue.
- 🔦 System Spotlight — one organization system, method, or tool examined in depth. HIL or otherwise.

**Rotating Content — appears based on what's ready:**
- ✂️ SKU Reduction Tip — practical assumed-kit philosophy. Quick and actionable.
- 📦 Storage Solution of the Issue — one product, hack, or configuration. Sponsorable eventually.
- 👤 People Showcase — real users, collectors, makers, community members. User submitted.
- 🪧 Sign of the Issue — HIL Sign Studio showcases. Community signs and creative addressing.
- 🎓 Education Corner — kids, homeschool, financial literacy through objects. Ties to Family Ledger.
- 🛠️ Tool History — manufacturer histories. Crossover content from r/maxtoolhistory.
- 🗂️ The Digital Index — applying HL grammar and organization logic to computer file systems. Folder structure, file naming, nesting traps, digital junk drawers.
- 🔧 HIL Update — what shipped, what's open on GitHub, community contributions.

**Future Segments (planned, not yet running):**
- 📊 Friction Report — recurring audit of one household problem area
- 🗺️ Coordinates — spatial and location-based organization content
- 🎲 The HIL Challenge — game or puzzle format, shareable

## Editorial Rules (12 laws)

1. Every issue must teach a system — not news, not announcements, not hacks
2. Start with ideas, not products — principle first, product optional
3. Focus on friction — lost items, duplicate purchases, clutter, missing records
4. Study proven systems — Red Cross, FEMA, libraries, museums, warehouses, military logistics
5. Show, don't lecture — short stories, case studies, real shops, real homes
6. The newsletter is a journal — Field Notes, Popular Mechanics, historical journals
7. Visual rules — blueprints, pegboards, maps, patent drawings, historical photos, diagrams. No stock photos, no tech startup imagery.
8. Image rule — 1 hero image, 1 optional supporting image, unlimited diagrams per issue
9. Every issue needs one actionable win — label a drawer, build a kit, reduce SKUs, archive records
10. Build the HIL world slowly — introduce HIL tools naturally, never as the main point
11. Core segments rotate — anchor content anchors, rotating content fills
12. The mission compass — if a story supports "everything has a place, everything can be found, everything can be learned" it belongs. If not, it doesn't.
