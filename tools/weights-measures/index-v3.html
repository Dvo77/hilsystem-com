WEIGHTS & MEASURES

Reading a real tool correctly is its own skill, separate from the math behind it — a tape measure, a protractor, a caliper all fail you the same way if you can't actually read the marks. Start here to build tool literacy: what to reach for, how precise it actually is, and how to read it without guessing.

ARCHITECT'S SCALE

SCALE SIMULATOR

roadmap · push, pull & platform scales · not yet built

Three different scale mechanisms read three different ways — a pull scale (hanging/spring, like a fish scale), a push scale (compression, like a bathroom scale), and a platform/balance scale. Volume and the fluid-ounce-vs-ounce mistake are a likely follow-on, not part of this build.

Ruler Simulator and Protractor Simulator are both content-complete prototypes reusing Calculator Explorer's Learn/Practice chassis — mode toggle, tap-to-explain, real grading engines. Both engines (the ruler's fraction parser, the protractor's degree/π-fraction formatter) were unit-tested standalone against known values before being wired into the UI, the same discipline Calculator Explorer's expression parser and Punctuation Explorer's answer bank used. Neither is wired to hil-shell.js or session-logger.js yet — same gap Punctuation Explorer had before this session, and the same porting work: mechanical at this point, not a design question. Scale Rule Simulator from the original proposal isn't on this roadmap yet — it teaches a genuinely different skill (reading a scaled drawing, not a physical tool) and deserves its own scoping pass rather than being assumed into this list.
